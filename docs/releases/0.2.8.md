## Funzioni principali

- Finestra Windows senza console o barra indirizzi; primo avvio con nuovo archivio vuoto, ripristino backup o riuso esplicito dei dati esistenti.

- Impostazioni con password mascherate e Windows DPAPI; avvisi delle configurazioni mancanti.
- Backup completo verificato, ripristino offline con copia preventiva, schede Backup e Aggiornamenti separate.
- Agenti con 14 agenti, Agenti AI e API Control; Dashboard sintetica.

## Installazione

Scaricare **Bettor-Setup-0.2.8-x64.exe** e il checksum `.sha256`. L'alias equivalente **Better-Setup-0.2.8-x64.exe** mantiene compatibili i client precedenti.

Chiudere la finestra e arrestare il servizio prima di aggiornare. Il setup conserva dati e impostazioni con backup verificato. Richiede Windows x64 e Microsoft Edge WebView2 Runtime; Python non ? richiesto sul PC utente. Su un altro account/PC le chiavi DPAPI possono richiedere nuovo inserimento.

Il setup non ? firmato digitalmente. Collaudo su un secondo PC/VM pulita e ispezione visiva automatizzata completa restano da effettuare. Nessuna modifica a soglie, gate, Validator o stake rules.

**Bettor non invia puntate ai bookmaker:** la conferma registra giocate e movimenti Banca; l'esecuzione esterna resta dell'utente.
