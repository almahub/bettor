# Bettor 0.2.7

Prima release stabile pubblica di questo aggiornamento desktop. Include tutte le funzionalità descritte nelle [note 0.2.6](0.2.6.md): finestra desktop, primo avvio guidato, credenziali protette, backup/ripristino, nuova navigazione e controlli sulle automazioni.

## Correzione di distribuzione

I test di API Control ora creano i propri export temporanei, senza dipendere da dati del PC di sviluppo. Un archivio senza export viene verificato esplicitamente: non vengono inventati consumi. Nessun export personale è incluso nei sorgenti o nel setup.

Il tag v0.2.6 resta nello storico; la relativa pipeline si è fermata ai test e non ha pubblicato una release stabile.

## Installazione

Scaricare **Bettor-Setup-0.2.7-x64.exe** e il relativo `.sha256`. L'alias **Better-Setup-0.2.7-x64.exe** ha contenuto identico e mantiene compatibili i client precedenti.

Chiudere la finestra e arrestare il servizio Bettor prima di aggiornare. Dati e impostazioni sono conservati con backup verificato. Richiesto Windows x64 e Microsoft Edge WebView2 Runtime. Il setup non è firmato digitalmente; su un altro PC/account le credenziali DPAPI possono richiedere nuovo inserimento.

Nessuna modifica a soglie, gate, Validator o regole di stake. Bettor non invia puntate ai bookmaker. Collaudo su un secondo PC/VM pulita e ispezione visiva automatizzata completa restano da effettuare.
